## Tentang Repository

Repository ini berisi panduan instalasi Linux di Windows menggunakan Windows Subsystem for Linux (WSL) 2 dengan distribusi Ubuntu.

Dokumentasi disusun untuk membantu pemula memahami konsep WSL, melakukan instalasi, menyelesaikan konfigurasi awal Ubuntu, memverifikasi hasil instalasi, dan mempelajari perintah dasar Linux.

## Tujuan

- Menyediakan dokumentasi berbahasa Indonesia yang mudah dipahami.
- Membantu mahasiswa dan pemula memulai pembelajaran Linux.
- Mendokumentasikan proses instalasi secara sistematis melalui README dan screenshot.
- Menjadi referensi belajar yang dapat dikembangkan lebih lanjut.

## Teknologi dan Referensi

- Windows 11
- Windows Subsystem for Linux (WSL) 2
- Ubuntu
- PowerShell / Windows Terminal
- Git dan GitHub
- [Dokumentasi resmi WSL](https://learn.microsoft.com/windows/wsl/)
